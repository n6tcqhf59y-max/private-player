# 私密播放器

只在这台 iPhone 上加密存放和播放私密视频。没有账号，也不会把视频上传到开发者的服务器。用 Safari 打开站点后，添加到主屏幕使用。

发布路径是 GitHub Pages 的站点根目录（`https://n6tcqhf59y-max.github.io/private-player/`）。不要改这个路径，也不要清理浏览器里已经保存的网站数据。

## 导入、播放和删除

1. 第一次打开时设置应用密码。密码至少 8 个字符，不明文保存。忘记密码后无法解密，也无法找回。
2. 点资料库右上角加号，从相册或「文件」导入。视频会在本机加密保存。
3. 点卡片播放。播放前会在本机解密。
4. 点卡片右上角可以删除。确认框里有「解密导出」「删除」和「取消」。

加密格式、资料库、应用密码和 `.ppb` 加密备份与原来兼容。备份仍然是加密的，必须用应用密码才能打开。

## 解密导出

解密导出只发生在本机：先解密出原视频，再交给 iPhone 的系统分享，由你自己存到「文件」、相册或你自己的网盘。

1. 在「删除这部视频？」里点「解密导出」。
2. 阅读提示后点「开始解密」。播放器只在这台设备上解密。
3. 解密完成后点「保存到系统…」。这一步需要你再次点击，因为 Safari 和主屏幕应用只允许在点击当时打开系统分享。
4. 在系统分享里保存。保存前如果离开本页，播放器会锁定并取消这次导出，不会删除加密副本。
5. 回到播放器后，只有你亲自确认「已经保存成功」，才会另外询问是否删除播放器里的加密副本。
6. 可以点「只导出，不删除」。

## 安全说明

导出的是未加密原视频，不再受播放器密码或面容保护。拿到这个文件的人可以直接播放。

系统分享的 Promise 完成，或者浏览器开始下载，都只表示系统接手了文件，不等于文件已经存进「文件」、相册或网盘。请打开保存位置自己检查。

取消、解密失败、密钥不对、分享失败，以及应用锁定，都不会删除播放器里的加密副本。

播放器不会把导出的视频上传到开发者的云，也不会发给第三方服务器。系统分享面板里如果由你自己选择网盘，那是你在系统里保存，文件此时已经是未加密原视频。

## 已安装的主屏幕应用

程序缓存版本是 `private-player-v2`。程序文件优先从网络更新，离线时才用缓存；缓存里只有程序，没有用户视频。更新服务工作线程时，如果当时还停在锁定或设置页，页面会自动刷新一次以加载新代码。正在播放或正在导出时不会为了更新而刷新。

## 开发者测试

测试只用合成的随机字节，不要把真实视频放进仓库或测试。

```bash
npm test
```

当前环境没有用真实 iPhone 验证系统分享面板。分享是否真正写入「文件」或相册，必须以你在手机上打开目标位置为准。
